2. The Python runtime
---------------------
DoMe runs on CPython 3.12 (Python Software Foundation License Version 2), which is in the _internal folder
(python312.dll, python3.dll and the Python standard library), with the libraries the runtime itself uses:
OpenSSL 3 (libcrypto-3.dll, libssl-3.dll; Apache License 2.0, licenses\Apache-2.0.txt), libffi (MIT),
SQLite (public domain) and Tcl/Tk 8.6 (the Tcl/Tk licence), plus zlib, bzip2, XZ Utils, Expat and
mpdecimal compiled into the runtime. Their notices are in Part 2 under "Python runtime", copied from the
Python installation the build used. vcruntime140.dll, vcruntime140_1.dll and, where present, msvcp140*.dll
are Microsoft Visual C++ runtime files, distributed under Microsoft's terms for distributable code.
